# Blade Step — порт на Godot 4

Порт веб-версии (исходники — в `../src`). Логика перенесена 1-в-1; места,
где нужна узкая правка под движок Godot, помечены `TODO`.

Открывайте **эту папку** как проект в Godot 4.3+ и жмите F5.


## Быстрый старт

1. Godot 4.3+ → «Импортировать» → выбрать `godot/project.godot`.
2. F5. Проект запускается без единого ассета — вся графика кодовая,
   весь звук синтезируется (как в веб-версии).

## Что уже перенесено

- Боевая логика (`logic.gd`) — полная, включая крит в прыжке, перекат,
  рассечение, удар щитом, отражение, отброс за край, инвариант «не делить клетку».
- ИИ всех личностей, наборы кубиков, «Путь героя».
- Звук и музыка (`audio.gd`) — пред-рендер PCM, звучит 1-в-1.
- Сеть (`net.gd`) — WebRTC-обмен SDP-кодами и LAN-режим через relay-сервер
  веб-версии (`../tools/lan-server.cjs`).
